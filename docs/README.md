# Project 文档索引

本目录是 Project 的工程文档入口。按文档用途组织，不按服务重复建立平行目录；文档状态和迁移规则见 [文档目录规划](./文档目录规划.md)。

## 当前推荐阅读

- [架构](./架构/README.md)：系统边界、领域模型和当前运行基线。
- [协议](./协议/README.md)：跨模块、跨服务的 API、存储和鉴权契约。
- [功能](./功能/README.md)：用户可见功能的行为和使用说明。

- [运维](./运维/README.md)：部署、升级、存储迁移、备份和故障恢复。
- [开发](./开发/README.md)：本地调试、脚本和生成式参考资料。

## 方案与历史

- [决策记录](./决策记录/README.md)：已批准的重要技术取舍及其替代方案。
- [提案](./提案/README.md)：尚未批准或尚未落地的设计，不作为生产依据。
- [历史归档](./历史归档/README.md)：被替代或废弃的内容，仅供背景参考。

## 生态边界

Project 是 YeYing 生态中的项目、任务、文件协作和团队工作流系统，拥有项目权限、任务状态和业务上下文；智能体安装、运行控制和社区发布目录属于相邻服务。跨系统边界以社区产品架构为总纲：

- [社区产品架构](https://github.com/yeying-community/books/blob/main/yeying/社区产品架构.md)

## 维护约定

- 新增文档按 [文档目录规划](./文档目录规划.md) 选择目录，并加入本索引或对应目录索引。
- 当前有效文档必须标注负责人和最后验证日期；草案、已废弃和历史文档必须显式标注状态。
- 生成式文档只能由对应脚本更新，不能手工修改生成内容。
- 涉及用户可见功能或 API 行为的变更，按文档规划检查 `resources/ai-kb/` 同步要求。
- `scripts/` 下脚本的用途和维护约定见 [scripts 脚本说明](./scripts-specification.md)。
