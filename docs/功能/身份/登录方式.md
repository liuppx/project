# 登录方式

## 目的和范围

Project 同时支持钱包/通行证登录和邮箱密码登录。钱包登录是默认入口；邮箱密码登录是可用的备用入口，用于钱包不可用、浏览器不支持或管理员需要恢复账号访问时登录。两种方式最终都创建 Project 自己的登录会话，并复用相同的用户、设备和权限校验。

## 钱包/通行证登录

1. 在登录页选择钱包登录并发起授权。
2. 夜莺钱包确认登录请求，通行证服务返回钱包身份和可验证声明。
3. Project 校验钱包地址、DID、身份声明和账号状态，并按邮箱声明补全或确认账号邮箱。
4. 校验通过后创建 Project 登录会话；如果需要用户在钱包中确认，页面会继续轮询当前登录会话状态。

已完成身份验证不等于每次都跳过登录确认：钱包仍需对新的登录会话签名或确认。邮箱声明必须是有效且已验证的邮箱，否则会返回需要设置并验证邮箱的错误。

## 邮箱密码登录

1. 在登录页切换到邮箱密码登录。
2. 输入已注册邮箱和密码，按页面提示完成图形验证码或邮箱验证。
3. 登录成功后进入 Project；失败时不会改变已有登录设备。

邮箱密码登录不是替代钱包登录的默认入口。管理员可以通过用户管理或 `./cmd repassword` 重置密码，但重置密码不会替换钱包身份绑定。

## 常见限制

- 钱包登录服务未配置时，登录页保留邮箱密码登录；不会自动请求公网身份服务。
- 钱包身份没有有效邮箱声明时，不能绕过邮箱验证直接完成需要邮箱的账号登录。
- 禁用用户、过期会话和无效签名均不能创建登录会话。
